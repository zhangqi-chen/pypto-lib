PyPTO3.0阶段报告

2026年7月

PyPTO 3.0 已完成 6 仓协同的全栈能力建设，在 A2/A3 打通 Qwen3-14B 与 DeepSeek-V4 Flash 端到端推理链路，实现 Token 推理生成，且性能与 AscendC 相当。

1. PyPTO3.0 Repos

pypto-serving

推理服务层，提供 OpenAI 兼容接口、模型加载、请求调度、Batching、KV Cache、采样与 NPU Worker。

pypto-lib

模型与算子库，基于 PyPTO DSL 实现可复用张量算子及 Qwen、DeepSeek 等端到端模型 Kernel。

pypto

编程框架与核心编译器，通过 Python Tensor/Tile DSL、多级 IR、编译 Pass 和 CodeGen 生成设备可执行代码。

simpler

任务运行时，构建并执行任务依赖图，协调 Host、AICPU 与 AICore 的调度、内存和同步。

PTOAS

汇编与优化器，基于 LLVM/MLIR 解析、校验并优化 .pto，生成调用 PTO-ISA 的 C++ Kernel。

PTO-ISA

Tile 虚拟指令集，定义并实现跨 A2/A3/A5 的标准计算、搬运、同步和通信指令，统一底层硬件接口。
